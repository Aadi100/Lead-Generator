# Lead Radar: app-wide design decisions (override MASTER.md where they differ)

MASTER.md came from the ui-ux-pro-max skill (`--design-system`, variance 4 / motion 4 / density 8). Its "Product Demo + Features" page pattern is for marketing sites and is IGNORED. Everything else (Flat / data-dense dashboard style, blue + green palette, Fira Sans + Fira Code, 150-200 ms transitions, visible focus, reduced motion) is adopted as below.

## 1. Direction
Professional, calm, data-dense operations console for one person who works leads all day. Flat surfaces separated by 1 px borders (no heavy shadows), colour only where it carries meaning (status, trust, category, primary action), generous whitespace around groups but tight inside rows. Light and dark themes are first-class (system default, manual toggle: Light / Dark / System, saved in localStorage inside try/catch, applied before first paint to avoid a flash).

## 2. Tokens (CSS variables on :root and [data-theme=dark]; Tailwind colours map to them; NO raw hex in components)
Light: bg #F8FAFC, surface #FFFFFF, surface-2 #F1F5F9, border #E2E8F0, border-strong #CBD5E1, fg #0F172A, fg-muted #475569, fg-subtle #64748B, primary #2563EB, on-primary #FFFFFF, primary-text #1D4ED8, primary-soft #EFF6FF, accent #059669, accent-soft #ECFDF5, ring #2563EB.
Dark: bg #0B1220, surface #111A2E, surface-2 #172238, border #243049, border-strong #334363, fg #E6ECF5, fg-muted #A5B2C7, fg-subtle #8394AE, primary #2563EB (fills keep white text), primary-text #7AA7FF, primary-soft #14233F, accent #34D399, accent-soft #0F2A25, ring #60A5FA.
Semantic (each with -soft tint background and -border): success light #047857 / dark #34D399; warning light #B45309 / dark #FBBF24; danger light #DC2626 / dark #F87171; info light #0369A1 / dark #38BDF8. Trust: High = success, Medium = warning, Low = danger. Lead status: New = info, Pitched = primary, Replied = accent, Won = success, Lost = danger, Ignored = neutral.
Category hues (dot + soft chip): Website blue #2563EB, App violet #7C3AED, Design pink #DB2777, Automation amber #D97706, Gaming emerald #059669, Other slate #64748B (use lighter variants in dark mode).
All text/background pairs >= 4.5:1 in both themes (verify the pairs you introduce); never convey meaning by colour alone (always an icon, word or shape too).

## 3. Type
Fira Sans (body, headings 600) and Fira Code (numbers in KPI tiles, tables, IDs, prices, scores; always `tabular-nums`), loaded with next/font/google (weights 400/500/600/700) and exposed as --font-sans/--font-mono. Scale: 12 caption, 13 dense table/meta, 14 base UI, 16 section title / inputs on touch, 20 page title, 28 KPI numbers. Line-height 1.5 body, 1.25 headings, `text-wrap: balance` on headings. Never below 12 px. Inputs are 16 px on mobile to stop iOS zoom.

## 4. Space, shape, density
4 px base; dense control height 32 px on desktop, 44 px minimum touch target on coarse pointers (`@media (pointer: coarse)`), 8 px minimum gap between adjacent targets. Radius: 6 controls, 10 cards/panels, full for chips/avatars. Page content max width 1440, side padding 16 (mobile) / 24 / 32. Borders instead of shadows; one soft shadow token only for floating layers (menus, drawers, modals, toasts). Reserve space for async content (skeletons the same size as the final content) so nothing jumps.

## 5. Motion tokens
--dur-fast 120 ms (hover/press), --dur 180 ms (menus, chips, tabs), --dur-slow 260 ms (drawers, modals, page content in); easing ease-out cubic-bezier(.2,.8,.2,1) for enter, ease-in for exit; exit = 60-70 % of enter. Animate only opacity and transform. New realtime lead: brief ring pulse + slide-in. List first paint: 30 ms stagger capped at 8 rows. `prefers-reduced-motion: reduce` removes all of it (state changes still show instantly).

## 6. Layout and navigation
Desktop >= 1024: left sidebar 240 px (collapsible to 68 px icon rail, state remembered) with the brand, grouped nav (Work: Leads, Outbox, Capture / Learn: Insights / System: Settings), live badges (drafts to review, unread replies, new leads), and at the bottom the worker status and the Pause/Resume sending control. Top bar 56 px: page title area, global search / command palette trigger (Ctrl+K, shows the shortcut), theme toggle, worker pill, user menu (email, sign out). Tablet 768-1023: collapsed rail. Mobile < 768: compact top bar + bottom tab bar with 5 items (Leads, Outbox, Capture, Insights, Settings), 64 px + safe-area inset, active state = filled icon + label + primary colour; the worker/pause/theme controls live in the top-bar menu. Skip-to-content link first in the tab order. Current page highlighted (aria-current="page"). Filters/tabs/selected lead live in the URL query string (shareable, Back works).
Command palette (Ctrl/Cmd+K): pages, settings tabs, quick actions (Pause/Resume sending, Find trade leads now, Refresh learning), recent leads by title; arrow keys + Enter, Esc closes, focus trapped, announces results count.

## 7. Component kit (src/components/ui/, all keyboard accessible, token-only colours, dark-mode aware)
Button (primary, secondary, ghost, danger; sm/md; loading with spinner and aria-busy; icon-only requires aria-label), IconButton, Input / Textarea / Select / Field (visible label, helper text, error text with aria-describedby, required marker), Switch, Checkbox, TagInput, SegmentedControl, Tabs (roving tabindex), Badge / Chip (status, trust, category, count), Card (surface + border + optional header/actions), StatTile (label, Fira Code value, delta/sub, optional sparkline), Table primitives (sticky header, row hover, selected state, sortable header, overflow-x container), Modal and Drawer (focus trap, Esc, scroll lock, return focus, 260 ms slide), Toast (aria-live polite, 4 s auto-dismiss, pause on hover, action button), Tooltip, Skeleton, EmptyState (icon, title, one-line help, primary action), Banner (info/warning/danger, dismissible), Kbd, Avatar/Initials, Divider, ProgressBar, Spinner, Sparkline and mini bar/funnel charts as hand-written SVG with text labels (never colour alone). Icons: one consistent inline-SVG set (Lucide-style, 1.75 stroke, 16/20 px) in src/components/Icons.tsx, always aria-hidden when decorative. No emoji as icons.

## 9. Quality bar (from the skill's checklist; verify with the screenshot tool in light, dark, 1440 px and 390 px)
No emojis as icons; cursor-pointer + hover + active + disabled + focus-visible on every interactive element; 4.5:1 contrast in both themes; focus never hidden by sticky bars; no horizontal page scroll at 360-1440; tables become horizontally scrollable containers or cards on mobile; loading uses skeletons not blank screens; destructive actions confirm; toasts auto-dismiss; labels always visible; errors next to fields; reduced motion respected; no layout shift on async updates; no raw hex or arbitrary px colours in components; no `dangerouslySetInnerHTML`; lead/reply text rendered as plain text.

## 11. ADDENDUM (user feedback: dark mode looked flat and bad; wants glass + good animations)
Dark theme is the showpiece. It must read as deep, layered and alive, never flat black with outlined boxes, and no text may ever sit at low contrast.
Canvas: a fixed full-viewport background (behind everything) = deep navy base (#070B14) + 3 very soft radial gradients (indigo top-left ~14 % opacity, emerald bottom-right ~9 %, violet mid-right ~8 %), optionally drifting slowly (transform only, 45-60 s loop, paused under reduced motion). Light theme gets the same idea in pastel (soft blue / mint blobs on #F4F7FB) so glass reads in both themes.
Glass (frosted translucent surfaces): utilities `.glass`, `.glass-strong`, `.glass-subtle` and Card/Panel `variant="glass"`. Dark values: background rgb(17 26 46 / .60) (strong .78, subtle .38), `backdrop-filter: blur(16px) saturate(140%)`, 1 px border rgb(255 255 255 / .09), inset top highlight rgb(255 255 255 / .06), shadow 0 10px 32px rgb(0 0 0 / .38). Light values: rgb(255 255 255 / .70) (strong .86, subtle .5), border rgb(15 23 42 / .08), shadow 0 8px 28px rgb(15 23 42 / .08). Use glass on: sidebar, top bar, cards/panels, drawers, modals, command palette, popovers, toasts, sticky toolbars and the mobile bottom bar. Do NOT blur individual list rows or table cells (performance): rows sit on one glass panel. Maximum 3 overlapping blurred layers. Always provide fallbacks: `@supports not (backdrop-filter: blur(1px))` and `@media (prefers-reduced-transparency: reduce)` switch to opaque surface tokens. Text on glass must stay >= 4.5:1 (raise opacity if needed); verify in screenshots over the brightest part of the canvas.
Dark controls: inputs/selects/textareas = translucent fill rgb(255 255 255 / .04), border rgb(255 255 255 / .10), hover border .18, focus = primary ring + soft glow (0 0 0 3px primary/25 %); placeholder fg-subtle at >= 4.5:1; select menus and date pickers use `color-scheme: dark`. Primary buttons: subtle top-to-bottom gradient of the primary, 1 px inner highlight, glow on hover (0 6px 20px primary/35 %); secondary = glass-subtle with border; focus-visible ring always.
Depth and meaning: use accent glows sparingly (active nav item, primary CTA, live indicators, new-lead pulse); status chips use tinted translucent backgrounds with a 1 px tinted border; page titles >= 7:1.
Motion system (all via tokens, transform/opacity only, disabled by prefers-reduced-motion): route/page enter (fade + 8 px rise, 260 ms; implement with app/template.tsx); staggered reveal for lists/grids/KPI tiles (`.stagger` with `--i` index, 40 ms steps, max 8); cards hover lift (-2 px, border brightens, soft glow, 180 ms) and press (scale .98, 120 ms); sidebar active item gets a sliding highlight pill (animated translate between items) and icon nudge on hover; StatTile numbers count up (600 ms ease-out) and sparklines draw in (stroke-dashoffset); chart bars grow from the baseline, funnel stages fill left to right; skeletons use a shimmer sweep; drawers/modals slide/scale in with a blurred backdrop fade (exit = 65 % of enter); toasts slide up with a countdown bar; command palette pops in; list inserts slide in with a brief highlight, removals collapse; tab underline slides; switch/checkbox have springy 180 ms transitions; theme toggle uses the View Transitions API with a circular reveal from the toggle button where supported (instant fallback); buttons show a 120 ms press and a spinner morph when loading. Reusable pieces to provide: `Stagger` wrapper, `CountUp`, `Reveal` (in-view fade/rise via IntersectionObserver), `Shimmer` skeleton, `PageTransition` (template.tsx), `ThemeToggle` with view transition, `AuroraBackground` (the canvas), and Tailwind animation utilities for all of the above.
Quality gate for dark mode: take screenshots in dark and light at 1440 and 390 for every page; zero invisible or low-contrast text, zero flat unlayered black areas, consistent glass panels, visible focus, no jank; fix before reporting.

## 10. Anti-patterns to avoid
Emoji icons, gradient hero banners, heavy drop shadows, one animation duration for everything, hover-only actions, placeholder-only labels, gray-on-gray text, icon-only buttons without labels, modals for everything (prefer drawers/panels), colour-only status, giant cards that push the data below the fold.
